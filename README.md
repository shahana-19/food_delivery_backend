# 🍔 Food Delivery Backend

A **Dockerized Django REST Framework backend** for a modern **Food Delivery App**, built with **Python**, **PostgreSQL**, and **Docker Compose**.

This backend powers core functionalities such as:
- 🍴 Restaurant management  
- 🧆 Menu and dishes  
- 🚗 Order handling and delivery tracking  
- 👤 User authentication and profiles  

---

## 🚀 Features

✅ Django + Django REST Framework  
✅ PostgreSQL Database  
✅ Docker & Docker Compose setup  
✅ Environment variable support (`.env`)  
✅ Ready for API integration with React frontend  

---

## 🧩 Tech Stack

| Component | Technology |
|------------|-------------|
| Language | Python 3.13 |
| Framework | Django 5 + Django REST Framework |
| Database | PostgreSQL 15 |
| Containerization | Docker, Docker Compose |
| Environment Config | python-dotenv |
